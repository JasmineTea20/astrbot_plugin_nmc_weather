# 中央气象台天气实况（nmcWeather）

从 [中央气象台](https://www.nmc.cn) 抓取**最新**天气实况图与天气公报，图片直接发到聊天里。

## 指令

| 指令 | 别名 | 参数 | 默认 |
|---|---|---|---|
| `/天气实况` | `/实况` | 类别 | 分类菜单 |
| `/天气图` | `/天气分析` | 区域 层次 类型 | 中国 · 地面 · 基本天气分析 |
| `/卫星云图` | `/云图` | 类别 子类型 | FY4B |
| `/雷达图` | `/雷达` | 类型 区域 | 雷达拼图 · 全国 |
| `/降水量` | `/降水` | 类型 时效 | 1小时降水量 |
| `/气温` | `/温度` | 类型 子类型 | 全国逐时气温 |
| `/风` | `/风场` | — | 全国逐时风 |
| `/能见度` | — | — | 能见度 |
| `/强对流` | — | 类型 | 雷电（地闪） |
| `/天气公报` | `/公报` | `文字` | 渲染成图 |

参数可省略、可用简称、可用序号：

```
/天气图                      → 中国 · 地面 · 基本天气分析
/天气图 亚欧                 → 亚欧 · 地面 · 基本天气分析
/天气图 850                  → 中国 · 850hPa · 基本天气分析
/天气图 亚欧 500 叠加         → 亚欧 · 500hPa · 叠加卫星云图
/降水量 24                   → 24小时降水量
/气温 逐日 日最高             → 全国逐日气温 · 日最高气温
/卫星云图 圆盘 水汽           → FY2G圆盘图 · 水汽圆盘图
/天气公报 文字               → 纯文本（不渲染图片）
```

参数写错时会返回该类别当前可用的全部选项，不会瞎猜。

## 实现说明

- **不硬编码图片地址**：入口页 HTML 里就带着「最新图的 URL」（`div.time[data-img]`）和「同级参数选项」（`div.p-nav`）。插件按参数在导航组里逐级跳转，终点页取第一张图 —— 站点新增层次/类型/卫星，插件自动跟上。
- 导航链接只保留同组上下文（跨组会重置），所以采用「多轮迭代 + 跳过已选中项」收敛多组参数。
- 页面缓存 60 s，公报内容缓存 10 min，同一会话 5 s 冷却（均可在配置里改）。
- 天气公报用 Pillow 自绘（服务器无 Chromium）：报头 / 签发 / 正文 / 内嵌预报图按原顺序排版，超页高自动分页，每页都带「(1/2)」页码并引用原消息回复。
- 图片下载失败会回退为直接发送源站 URL；下载的临时文件 1 小时后自动清理。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `cache_ttl` | 60 | 页面缓存秒数 |
| `timeout` | 15 | 单次请求超时秒数 |
| `cooldown` | 5 | 同一会话冷却秒数，0 关闭 |
| `render_width` | 900 | 公报图宽度（px） |
| `page_split_height` | 3000 | 公报单页最大高度（px） |
| `max_pages` | 4 | 公报最多发几页 |
| `bulletin_text_limit` | 1200 | 文字版字符数上限 |
| `font_path` | `/usr/share/fonts/chinese/msyh.ttc` | 中文字体，留空自动探测 |

## 数据来源

中央气象台 www.nmc.cn（图片托管于 image.nmc.cn）。插件只做抓取转发，版权归中国气象局所有。
